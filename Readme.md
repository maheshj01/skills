### Agent Skills

Agent Skills are well defined prompts with examples and patterns your agent can use to perform a specific task more effectively.

### Install

```bash
npx skills add maheshj01/skills --skill <skill-name>
```

Add `-g` to install a skill for every project, and `-a claude-code` to pick the agent.
